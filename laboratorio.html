2. CSS básico

CSS permite dar estilo a los elementos HTML: colores, tamaños, espacios, bordes y distribución.

Selector y color

El selector indica qué elemento se modifica. color cambia el color del texto.

p { color: brown; }

Tipografía

font-family cambia el tipo de letra y font-size su tamaño.

h2 { font-size: 24px; }

Fondo y bordes

background-color establece el fondo y border agrega un borde.

div { border: 1px solid #333; }

Modelo de caja

Incluye contenido, relleno (padding), borde y margen (margin).

Contenido dentro de la caja

Flexbox

display: flex facilita distribuir elementos en filas o columnas.

UnoDosTres

Unidades

px representa píxeles, % es relativo al contenedor y rem al tamaño de letra raíz.
